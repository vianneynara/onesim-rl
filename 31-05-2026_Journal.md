## 1. Using the last 100 episodes aggregated trajectory distribution for better visualization

Using 1 day, 3 days, and 7 days per episode in the simulation lacks the information to visualize the impact of searching
time for the models.
I almost finished chapter 4, but comparing the Searching Success Rate (SSR) of the models prove the informed models
being able to find most of the targets in the space.
Meanwhile, Epsilon Greedy tanks its performance, Lévy Flight was able to outperform the models on the first day.
The models though, were able to detect the targets more often (not coverage) than Lévy Flight, which is a good sign 
that they are learning to find more targets by minimizing the energy (steps) being used.

Additionally, I want to also compare the performance, given time of only 172800 seconds (2 day) per episode.
We should extract the trained models in `2d-cont-` prefixed folders.
So after the simulation, we'll be able to compare 1 day, 2 days, 3 days, 7 days performance.

To silently implement endTime override, I modified this part in batch_runner.py (hard-coded):

```python
# Add overrides only if provided
if overrides_string:
    # script.extend(["-d", overrides_string]) # Default simulation settings
    script.extend(["-d", overrides_string + "@@Scenario.endTime=172800"]) # Using 3 day simulation
```

Which will append a phantom param `@@Scenario.endTime=172800` to the simulation script.
This will make the simulation run for 1 day, but not affecting the overrides list on `run_id`.
